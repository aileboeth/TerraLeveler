# TerraLeveler

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | **한국어** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Português (Brasil)](README.pt-BR.md)

TerraLeveler는 Minecraft용 Fabric **클라이언트** 모드입니다. 서바이벌 모드에서 자신의 플레이어를 조종해 영역을 지정한 높이로 평평하게 고르거나(직접 선택한 직사각형 또는 섬 전체), 영역을 횃불로 밝힙니다. 평범한 걷기, 채굴, 설치, 보관함 조작만 사용하며 언제든지 일시 정지, 재개, 중지할 수 있습니다.

> 게임 내 화면(설정 화면과 채팅 메시지)은 현재 중국어만 지원합니다.

## 기능

### 지형 평탄화

- **영역 선택:** 일반 사과를 들고 좌클릭으로 첫 번째 모서리, 우클릭으로 반대쪽 모서리를 지정합니다. 또는 섬 자동 감지를 켜면 서 있는 땅을 기점으로 주변의 이어진 수면을 따라 섬 전체를 찾아냅니다. 큰 섬은 구역별로 작업합니다.
- 목표 높이보다 위에 있는 블록을 모두 제거하고, 목표 높이에 흙 / 잔디 블록 지표를 한 층 깝니다. 지표 아래의 동굴과 액체는 채우지 않습니다.
- 스스로 길을 찾습니다. 높은 곳에 닿아야 할 때는 임시 발판이나 기둥을 세우고 작업이 끝나면 회수합니다. 발판 블록 수는 발판 예산으로 제한되며 로컬 장부에 기록되므로, 월드에 다시 들어와도 남은 발판을 회수할 수 있습니다.
- 액체 처리: 목표 높이보다 위의 물을 메우고, 먼저 영역 밖에서 흘러드는 수원을 찾아 막으려고 합니다.
- 물 양동이가 있으면 높은 곳에서 내려올 때 물 양동이로 착지합니다.
- 보관함과 블록 엔티티 보호(기본값 켜짐): 상자, 셜커 상자, 화로 같은 블록을 만나면 일시 정지하고 좌표를 알려 줍니다.

### 영역 조명

- 사과로 3D 영역의 두 모서리를 지정합니다. 블록 광원이 기준값 이하인 설치 가능한 모든 바닥에 횃불을 놓습니다(하늘빛은 보지 않습니다). 횃불은 인벤토리의 셜커 상자에서 꺼내 쓸 수 있습니다.

### 두 모드 공통

- 도구 내구도가 보호값까지 떨어지면 도구를 바꿉니다. 지정한 이름의 셜커 상자("도구 상자")에서 교체용 도구를 꺼낼 수도 있습니다.
- 모은 흙 같은 재료가 한도를 넘으면 남는 양을 인벤토리의 셜커 상자에 넣어 두고, 지표에 재료가 모자라면 다시 꺼냅니다(Quick Shulker로 상자를 열기 때문에 화면이 뜨지 않습니다).
- 공격해 오는 몹에게 반격하고, 자동으로 음식을 먹고, 물이나 용암에 빠지면 빠져나옵니다. 체력이 낮아지면 일시 정지하고 회복되면 다시 작업합니다.
- 길을 막는 일반 동물을 처리합니다. 주민, 골렘, 길들인 펫과 말, 이름을 붙였거나 끈으로 묶은 동물은 공격하지 않고 돌아가거나 비켜 줄 때까지 기다립니다.
- 현재 상태와 진행률을 화면에 표시합니다. 일시 정지하면 채팅으로 이유를 알려 주고, 직접 처리해야 할 때는 알림음을 냅니다.
- 문제 해결을 위한 진단 로그(선택 사항).

TerraLeveler 자체는 클라이언트에만 설치하면 됩니다. 멀티플레이 서버에서 셜커 상자 관련 기능을 쓰려면 서버에도 Quick Shulker가 있어야 합니다. 서버에 없으면 남는 재료는 그냥 버리고, 흙이 모자랄 때는 영역 안에서 목표 높이보다 위에 있는 흙을 파서 보충합니다.

## 설치

1. 사용하는 Minecraft 버전의 Fabric Loader를 설치합니다.
2. 그 버전용 TerraLeveler JAR와 위 표의 필수 모드를 게임 디렉터리의 `mods` 폴더에 넣습니다.
3. 게임을 실행합니다.

## 사용법

### 설정 열기

- MaLiLib 설정 메뉴를 열고(MaLiLib 기본 단축키는 `A + C`) 위쪽에서 TerraLeveler를 선택하거나,
- Mod Menu의 모드 목록에서 TerraLeveler의 "설정" 버튼을 누릅니다.

설정에서 작업 모드(지형 평탄화 / 영역 조명)를 고르고 각 항목을 조정합니다. 변경 사항은 바로 저장됩니다.

### 단축키 지정

TerraLeveler의 단축키는 **기본적으로 모두 지정되어 있지 않습니다**. 처음 사용하기 전에 설정에서 지정하세요.

| 단축키 | 기능 |
|---|---|
| 시작 / 중지 | 대기 중이면 작업 시작, 작업 중이거나 일시 정지 중이면 중지 |
| 일시 정지 / 재개 | 현재 작업을 일시 정지하거나 계속 |
| 목표 높이 기록 | 발밑의 완전한 블록 높이를 목표 지면 높이로 기록(설정에서 Y 값을 직접 입력할 수도 있음) |
| 보관 아이템 기록 | 주 손의 아이템을 사용자 보관 목록에 추가하거나 제거. 목록의 아이템은 버리지 않음 |

채팅 메시지에는 실제로 지정한 키가 표시됩니다.

### 직사각형 평탄화

1. 설정에서 지형 평탄화 모드를 고릅니다.
2. 원하는 지면 높이에 서서 "목표 높이 기록"을 누르거나, 설정에서 목표 Y를 입력합니다.
3. 주 손에 일반 사과를 들고 좌클릭으로 한 모서리, 우클릭으로 반대쪽 모서리를 지정합니다.
4. "시작 / 중지"를 누릅니다.

### 섬 전체 평탄화

1. 설정에서 섬 자동 감지를 켜고, 필요하면 관련 항목(남겨 둘 해안 폭, 섬 안의 연못도 평탄화할지 등)을 조정합니다.
2. 목표 높이를 기록한 뒤 섬 위에 서서 "시작 / 중지"를 누릅니다. 처음 누르면 감지 결과 미리 보기가 나오고, 한 번 더 누르면 확정하고 작업을 시작합니다.

섬 모드가 켜져 있으면 사과로 지정한 모서리는 쓰이지 않고 감지된 섬 범위를 사용합니다.

### 영역 조명

1. 설정에서 영역 조명 모드를 고릅니다.
2. 사과의 좌클릭과 우클릭으로 3D 영역의 두 모서리를 지정하고 "시작 / 중지"를 누릅니다.

### 파일 위치

아래 파일은 모두 게임 디렉터리 안에 있습니다(런처에서 버전별로 폴더를 분리했다면 `.minecraft/versions/<버전 이름>/`).

- `config/terraleveler.json`: 설정
- `config/terraleveler-scaffold-ledgers.json`: 임시 발판 장부(직접 비우지 마세요. 비우면 남은 발판을 자동으로 회수할 수 없습니다)
- `config/terraleveler-island-survey/`: 섬 감지 때 기록한 지형 데이터
- `logs/terraleveler-diagnostic.log`: 진단 로그(설정의 진단 로그 항목으로 켜고 끔. 그 항목의 설명에 이 컴퓨터의 전체 경로가 표시됩니다)

예전 이름인 WETA(WorldEater Trench Assistant)에서 업그레이드하면, 예전 `weta.json` 등의 파일은 처음 실행할 때 새 이름으로 복사됩니다. `mods`에서 예전 `worldeater-trench-assistant-*.jar`를 지우세요. 지우지 않으면 새 모드와 예전 모드가 동시에 실행됩니다.

### 알아 둘 점

- 자동 작업은 시점 회전, 이동, 블록 파괴를 매우 자주 합니다. 안티치트가 있는 서버에서는 위반으로 판정될 수 있으니 먼저 서버 규칙을 확인하세요.
- 작업 중에는 일반 사과를 영역 선택용으로 남겨 두며 자동으로 먹지 않습니다.
- 작업 중에 직접 움직이면 수동 조작으로 넘어간 것으로 보고 작업을 일시 정지합니다.

## 소스에서 빌드

JDK 25가 필요합니다. 사용하는 Minecraft 버전의 브랜치(26.1.2는 `main`, 26.3은 `mc-26.3`)를 체크아웃한 뒤 프로젝트 루트에서 실행합니다.

```bash
./gradlew directTest build -x test
```

Windows에서는 `gradlew.bat directTest build -x test`를 사용합니다. 모드 JAR는 `build/libs/terraleveler-<버전>.jar`에 생성됩니다(같은 위치의 `-sources.jar`는 소스 코드입니다).

`directTest`는 Minecraft의 블록과 아이템 레지스트리를 먼저 초기화한 뒤 JUnit Platform Console Launcher로 모든 테스트를 실행합니다. Gradle 표준 `test` 작업은 이 초기화를 하지 않아 일부 테스트가 `Not bootstrapped`로 실패하므로, 빌드할 때 `-x test`로 건너뜁니다.

프로젝트 구조:

```text
src/client/java/      클라이언트 소스 코드(cn.terraleveler)
src/client/resources/ Mixin 설정
src/main/resources/   fabric.mod.json과 아이콘
src/test/java/        단위 테스트
libs/                 컴파일 전용 의존성(Mod Menu, 모드에 포함되지 않음)
tools/Make-Icon.ps1   모드 아이콘을 만드는 PowerShell 스크립트
```

버전 번호는 `gradle.properties`의 `mod_version`에서 설정합니다.
