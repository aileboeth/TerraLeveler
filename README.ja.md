# TerraLeveler

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Português (Brasil)](README.pt-BR.md)

TerraLeveler は Minecraft 用の Fabric **クライアント** Mod です。サバイバルモードで自分のプレイヤーを操作し、範囲を指定した高さまで整地する（自分で選んだ長方形、または島全体）か、範囲を松明で明るくします。通常の歩行・採掘・設置・コンテナ操作だけを使い、いつでも一時停止・再開・停止できます。

> ゲーム内の画面（設定画面とチャットメッセージ）は現在中国語のみです。

## 機能

### 整地

- **範囲選択：**普通のリンゴを持ち、左クリックで 1 つ目の角、右クリックで対角を指定します。または島の自動検出をオンにすると、立っている陸地を起点に、周囲を囲む連続した水面から島全体を検出します。大きな島は区画ごとに作業します。
- 目標の高さより上のブロックをすべて取り除き、目標の高さに土 / 草ブロックの地表を 1 層敷きます。地表より下の洞窟や液体は埋めません。
- 自分で経路を探します。高い場所に届かないときは仮の足場や柱を立て、作業が終わると回収します。足場ブロックの数は足場の予算で制限され、ローカルの台帳に記録されるので、ワールドに入り直しても残った足場を回収できます。
- 液体の処理：目標の高さより上の水を埋め、まず範囲外から流れ込む水源を探してふさぎます。
- 水バケツを持っていれば、高所から降りるときに水バケツで着地します。
- コンテナとブロックエンティティの保護（デフォルトでオン）：チェスト、シュルカーボックス、かまどなどに当たると一時停止して座標を報告します。

### 範囲照明

- リンゴで 3D 範囲の 2 つの角を指定します。ブロック光がしきい値以下の、設置できるすべての床に松明を置きます（空の光は見ません）。松明はインベントリ内のシュルカーボックスから取り出せます。

### 両モード共通

- ツールの耐久値が保護値まで下がるとツールを持ち替えます。指定した名前のシュルカーボックス（「ツールボックス」）から交換用ツールを取り出すこともできます。
- 集めた土などの素材が上限を超えると、余りをインベントリ内のシュルカーボックスにしまい、地表に足りなくなったら取り出します（Quick Shulker で箱を開くため、画面は開きません）。
- 攻撃してくるモブに反撃し、自動で食事をし、水や溶岩に落ちたら脱出します。体力が低くなると一時停止し、回復すると再開します。
- 道をふさぐ普通の動物を排除します。村人、ゴーレム、飼いならしたペットや馬、名前を付けた動物やリードでつないだ動物は攻撃せず、避けて通るか、どくのを待ちます。
- 現在の状態と進捗率を画面に表示します。一時停止すると理由をチャットで伝え、対応が必要なときは音で知らせます。
- トラブル調査用の診断ログ（任意）。

## 動作要件

| | Minecraft 26.3 | Minecraft 26.1.2 |
|---|---|---|
| Fabric Loader | 0.19.5 以上 | 0.19.3 以上 |
| Java | 25 以上 | 25 以上 |
| [Fabric API](https://github.com/FabricMC/fabric) | 必須（0.163.0+26.3 でビルド） | 必須（0.154.2+26.1.2 でビルド） |
| [MaLiLib](https://github.com/maruohon/malilib) | 必須、0.30.2 以上（設定画面） | 必須、0.28.6 以上 |
| [Quick Shulker](https://github.com/MoRanpcy/quickshulker) | 必須、26.3 版（3.1.1-26.3 で動作確認） | 必須、26.1.2 版 |
| [Mod Menu](https://github.com/TerraformersMC/ModMenu) | 任意、Mod 一覧に「設定」ボタンを追加 | 任意 |

TerraLeveler 本体はクライアントに入れるだけで動きます。マルチプレイでシュルカーボックス関連の機能を使うには、サーバーにも Quick Shulker が必要です。サーバーにない場合、余った素材はその場で捨て、土が足りないときは範囲内の目標の高さより上にある土を掘って補います。

## インストール

1. 使う Minecraft バージョンの Fabric Loader をインストールします。
2. そのバージョン用の TerraLeveler の JAR と、上の表の必須 Mod をゲームディレクトリの `mods` フォルダーに入れます。
3. ゲームを起動します。

## 使い方

### 設定を開く

- MaLiLib の設定メニューを開き（MaLiLib のデフォルトのホットキーは `A + C`）、上部で TerraLeveler を選びます。
- または Mod Menu の Mod 一覧で TerraLeveler の「設定」ボタンを押します。

設定で作業モード（整地 / 範囲照明）を選び、各項目を調整します。変更はすぐに保存されます。

### ホットキーの割り当て

TerraLeveler のホットキーは**デフォルトではすべて未割り当て**です。初めて使う前に設定で割り当ててください。

| ホットキー | 動作 |
|---|---|
| 開始 / 停止 | 待機中なら開始、作業中や一時停止中なら停止 |
| 一時停止 / 再開 | 現在の作業を一時停止または再開 |
| 目標の高さを記録 | 足元の完全なブロックの高さを目標の地面の高さとして記録（設定で Y 座標を直接入力することもできます） |
| 保持アイテムを記録 | メインハンドのアイテムを独自の保持リストに追加または削除。リストのアイテムは捨てられません |

チャットのメッセージには、実際に割り当てたキーが表示されます。

### 長方形の整地

1. 設定で整地モードを選びます。
2. 目標の地面の高さに立って「目標の高さを記録」を押すか、設定で目標の Y を入力します。
3. メインハンドに普通のリンゴを持ち、左クリックで一方の角、右クリックで対角を指定します。
4. 「開始 / 停止」を押します。

### 島全体の整地

1. 設定で島の自動検出をオンにし、必要に応じて関連する項目（岸辺を残す幅、島内の池も整地するかなど）を調整します。
2. 目標の高さを記録してから島の上に立ち、「開始 / 停止」を押します。1 回目は検出結果のプレビューが表示され、もう一度押すと確定して作業を始めます。

島モードがオンのときはリンゴで指定した角は使われず、検出した島の範囲が使われます。

### 範囲照明

1. 設定で範囲照明モードを選びます。
2. リンゴの左クリックと右クリックで 3D 範囲の 2 つの角を指定し、「開始 / 停止」を押します。

### ファイルの場所

以下のファイルはすべてゲームディレクトリ内にあります（ランチャーでバージョンごとにフォルダーを分けている場合は `.minecraft/versions/<バージョン名>/`）。

- `config/terraleveler.json`：設定
- `config/terraleveler-scaffold-ledgers.json`：仮の足場の台帳（手動で消さないでください。消すと残った足場を自動で回収できなくなります）
- `config/terraleveler-island-survey/`：島の検出時に記録した地形データ
- `logs/terraleveler-diagnostic.log`：診断ログ（設定の診断ログの項目でオン / オフ。その項目の説明にこのコンピューター上のフルパスが表示されます）

旧名称 WETA（WorldEater Trench Assistant）からアップグレードすると、古い `weta.json` などのファイルは初回起動時に新しい名前でコピーされます。`mods` から古い `worldeater-trench-assistant-*.jar` を削除してください。削除しないと新旧両方の Mod が同時に動きます。

### 注意点

- 自動作業では視点の回転、移動、ブロックの破壊を頻繁に行います。アンチチートのあるサーバーでは違反と判定される可能性があるので、先にサーバーのルールを確認してください。
- 作業中、普通のリンゴは範囲選択用に取っておかれ、自動で食べられることはありません。
- 作業中に手動で移動すると手動操作への切り替えとみなされ、作業は一時停止します。

## ソースからのビルド

JDK 25 が必要です。使う Minecraft バージョンのブランチ（26.1.2 は `main`、26.3 は `mc-26.3`）をチェックアウトし、プロジェクトのルートで次を実行します。

```bash
./gradlew directTest build -x test
```

Windows では `gradlew.bat directTest build -x test` を使います。Mod の JAR は `build/libs/terraleveler-<バージョン>.jar` に出力されます（同じ場所の `-sources.jar` はソースコードです）。

`directTest` は Minecraft のブロックとアイテムのレジストリを先に初期化してから、JUnit Platform Console Launcher ですべてのテストを実行します。Gradle 標準の `test` タスクはこの初期化を行わないため、一部のテストが `Not bootstrapped` で失敗します。そのためビルドでは `-x test` で省略しています。

プロジェクト構成：

```text
src/client/java/      クライアントのソースコード（cn.terraleveler）
src/client/resources/ Mixin の設定
src/main/resources/   fabric.mod.json とアイコン
src/test/java/        ユニットテスト
libs/                 コンパイル時のみの依存関係（Mod Menu。Mod には同梱されません）
tools/Make-Icon.ps1   Mod のアイコンを生成する PowerShell スクリプト
```

バージョン番号は `gradle.properties` の `mod_version` で設定します。
